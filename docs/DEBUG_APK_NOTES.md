APK de test Pluxy **1.5.1 (46)** pour Android TV/mobile et Pluxy Serveur Android,
hors Google Play. Les versions, certificats, commit source et run de validation figurent
dans `BUILD_INFO.json` ; `SHA256SUMS.txt` permet de vérifier les téléchargements.

**Changement de signature le 4 octobre 2026 : les anciennes installations portant une
autre signature ne peuvent pas recevoir directement ces APK.** Sauvegardez les réglages
disponibles, désinstallez l'ancienne application puis installez celle-ci. La désinstallation
efface ses données privées et impose de reconfigurer les permissions et dossiers.
Les médias conservés hors de l'application restent sur leur support.

Deux clés stables distinctes sont utilisées, une pour le lecteur et une pour le serveur
Android. Les mises à jour avec le même certificat conservent normalement les données.
Les clés Google Play restent séparées.

Consultez le [guide de signature et de migration](https://github.com/Amau54/Pluxy/blob/main/docs/DEBUG_SIGNING.md)
avant de changer de canal.
